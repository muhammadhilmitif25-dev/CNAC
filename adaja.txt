# Vector Space Model – Information Retrieval

Implementasi Vector Space Model (VSM) untuk sistem temu balik informasi menggunakan Python.

---

## Cara Menjalankan Program

### 1. Install dependensi
```bash
py -m pip install -r requirements.txt
```

### 2. Jalankan program
```bash
py -3.14 vsm.py base.txt query1.txt
```

Untuk menjalankan dengan query yang berbeda:
```bash
py -3.14 vsm.py base.txt query2.txt
py -3.14 vsm.py base.txt query3.txt
```

**Argumen:**
| Argumen | Keterangan |
|---|---|
| `base.txt` | File berisi daftar nama file dokumen (satu per baris) |
| `query1.txt` | File berisi query pencarian |

---

## Penjelasan Algoritma

Program bekerja melalui 8 langkah utama:

### Langkah 1 – Preprocessing
Setiap dokumen dan query dibersihkan dulu sebelum diproses:
- **Lowercase** – semua huruf dijadikan kecil
- **Tokenisasi** – teks dipecah menjadi kata-kata individual
- **Hapus stopwords** – kata umum yang tidak penting dihapus (contoh: the, is, and, a, in)
- **Stemming** – kata dipotong ke bentuk dasarnya menggunakan Porter Stemmer
  - Contoh: `retrieval` → `retriev`, `learning` → `learn`, `documents` → `document`

### Langkah 2 – Hitung TF (Term Frequency)
Mengukur seberapa sering sebuah kata muncul dalam satu dokumen.

```
TF = 1 + log10(frekuensi)
```

### Langkah 3 – Hitung IDF (Inverse Document Frequency)
Mengukur seberapa langka sebuah kata di seluruh koleksi dokumen.
Kata yang muncul di semua dokumen dianggap kurang penting (IDF rendah).

```
IDF = log10(N / n)
N = total jumlah dokumen
n = jumlah dokumen yang mengandung kata tersebut
```

### Langkah 4 – Hitung TF-IDF
Bobot akhir setiap kata dihitung dengan mengalikan TF dan IDF.

```
TF-IDF = TF × IDF
```

### Langkah 5 – Buat Inverted Index
Daftar kata beserta dokumen mana saja yang mengandungnya, beserta bobotnya.

```
kata: nomor_dok,bobot  nomor_dok,bobot  ...
```

### Langkah 6 – Preprocessing Query
Query diproses dengan cara yang sama seperti dokumen (tanpa operator AND/OR/NOT).

### Langkah 7 – Hitung Cosine Similarity
Mengukur kemiripan antara vektor dokumen dan vektor query.
Nilai mendekati 1.0 berarti sangat mirip, nilai 0.0 berarti tidak mirip sama sekali.

```
Similarity(d, q) = (vd · vq) / (||vd|| × ||vq||)
```

### Langkah 8 – Perangkingan
Dokumen diurutkan berdasarkan nilai cosine similarity dari tertinggi ke terendah.

Query setelah preprocessing: ['vector', 'space', 'model', 'inform', 'retriev']

=== HASIL PERANGKINGAN ===
  1. doc1.txt         similarity = 1.0000
  2. doc5.txt         similarity = 0.1234

  4. doc3.txt         similarity = 0.0000

[OK] Inverted index ditulis ke index.txt
[OK] Bobot TF-IDF ditulis ke weights.txt
[OK] Hasil perangkingan ditulis ke response.txt

Selesai!

### index.txt
```
inform: 1,0.3010  5,0.3010

```
